# Восстановление медиатеки Яндекс Диска

Десктопное Java-приложение для бережного восстановления локальной медиатеки, когда часть файлов Яндекс Диска осталась только как облачные заглушки, но их миниатюры видны в Проводнике.

## Запуск

Требуется JDK 21 или новее.

```powershell
.\gradlew.bat run
```

Первое окно уже содержит исходную папку `%USERPROFILE%\Yandex.Disk` и папку восстановления `D:\YandexDisk-BACKUP`. Их можно изменить кнопками выбора. Каждый подтверждённый выбор сразу сохраняется рядом с программой в `yandex-media-recovery.properties`.

## Что делает программа

1. Рекурсивно обходит исходную папку.
2. Открывает каждый поддерживаемый файл. Декодируемые фото и видео копирует в ту же относительную папку назначения.
3. Для недоступного или повреждённого медиа запрашивает у Windows Shell миниатюру. Это позволяет Яндекс Диску/Проводнику вернуть уже сохранённое или доступное превью. Сохранённый PNG получает имя `PREW_<исходное-имя-без-расширения>.png`.
4. Не заменяет ни один файл в целевой папке: существующий оригинал или существующее `PREW_`-превью означает пропуск.

Панель прогресса показывает номер текущего файла, а журнал — действие и путь для каждого файла. Ошибки отдельных файлов не прерывают остальную операцию.

Для каждого запуска рядом с программой создаётся файл `recovery-log-ГГГГ-ММ-ДД_чч-мм-сс.csv`. В нём после обработки каждого файла сразу сохраняется строка `path,file_name,status`. Статусы: `SRC_SAVED`, `PREVIEW_SAVED`, `NO_FILE`, `ALREADY_OK`.

## Ограничения

Цвет оверлея Яндекс Диска (зелёная галочка/синие стрелки) не доступен Java как надёжное файловое свойство. Перед проверкой содержимого программа использует стандартный Windows-флаг `dos:offline`, чтобы не открывать и не гидратировать облачную заглушку; полный файл всё равно копируется только после реального декодирования. Если у Windows/Yandex Disk нет миниатюры и полного файла нет, изображение восстановить технически невозможно — это будет отражено в журнале как «Превью недоступно в кэше Windows».

## Проверка

```powershell
.\gradlew.bat test build
```

Тесты проверяют декодирование, сохранение относительных путей, приоритет уже существующих файлов и запись PNG-превью.
