# Восстановление медиатеки Яндекс Диска

Утилита для бережного сохранения фотографий и видео из локальной папки Яндекс Диска, когда часть оригиналов осталась облачными заглушками, но доступна в виде превью.

## [⬇️ Скачать последнюю версию](https://github.com/Bati4eli/YandexMediaRecovery/releases/latest)

Скачайте ZIP из раздела **Releases** и распакуйте его целиком.

Перед первым запуском обязательно дважды нажмите `download-dependencies.bat`. Он скачает Java Runtime и нужные библиотеки в папку приложения. После этого можно запускать `YandexMediaRecovery.exe` даже на компьютере без установленной Java. Для этого первого шага нужны интернет и PowerShell; Chrome устанавливается отдельно.

## Что делает программа

1. Пользователь выбирает корень локального Яндекс Диска, папки для обработки и папку резервной копии.
2. Программа сохраняет структуру каталогов и не изменяет исходные файлы.
3. Если в резервной папке уже есть оригинал, файл пропускается.
4. Если доступен и успешно декодируется оригинал — он копируется как самый качественный результат.
5. Если оригинала нет, программа по очереди пытается получить превью:
   - большое локальное превью Windows Explorer — `PREW_`;
   - большое превью из авторизованного веб-клиента Яндекс Диска — `WEBPV_`;
   - маленькую обложку Windows Explorer — `MINIPV_`.
6. При включённой очистке менее качественные превью удаляются только из папки резервной копии. Оригиналы никогда не удаляются.

Приоритет качества: `ORIGIN` → `WEBPV_` → `PREW_` → `MINIPV_`.

Во время работы есть прогресс, экранный журнал и CSV-журнал. Настройки путей и выбранных папок сохраняются в `yandex-media-recovery.yaml` рядом с программой.

Для получения серверных превью нажмите «Войти в Яндекс Диск…» и выполните вход в открывшемся Chrome. Пароли, cookie и токены в настройки и журналы не записываются.
