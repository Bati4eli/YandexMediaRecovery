# Восстановление медиа Яндекс Диска

## Цель

Приложение восстанавливает локальную коллекцию после повреждения серверов Яндекс Диска. Оно рекурсивно обходит выбранную исходную папку и создаёт в выбранной папке восстановления безопасную копию структуры каталогов:

* Полный файл фото или видео копируется только если он действительно открывается/декодируется.
* Если полного файла нет или он повреждён, приложение пытается сохранить доступное в Windows Explorer превью как PNG с префиксом `PREW_`.
* Уже существующий путь в папке восстановления имеет абсолютный приоритет: его не менять и не перезаписывать.

## Разработка

* Java 21, Gradle, Swing. Основные границы: UI, конфигурация, планирование, проверка медиа, получение превью и файловые операции.
* Не определять статус по цвету оверлея Яндекс Диска: Explorer не предоставляет его как стабильный файловый атрибут. Перед декодированием учитывать Windows-флаг `dos:offline`, чтобы не гидратировать облачную заглушку; надёжный критерий полного файла — успешное декодирование. Windows Shell применяется для извлечения миниатюры.
* Перед изменением бизнес-логики написать или обновить JUnit-тесты. Проверять как минимум: приоритет папки назначения, сохранение относительного пути, классификацию читаемого/нечитаемого файла и идемпотентность повторного запуска.
* Не удалять и не перезаписывать данные источника или назначения. Любая ошибка одного файла записывается в итог и не прерывает весь обход.
* Папки сохранять сразу после подтверждения выбора в `yandex-media-recovery.properties` рядом с программой. Для каждого запуска создавать рядом с программой CSV-лог с датой и временем в имени; строку для каждого обработанного файла сразу сбрасывать на диск. Допустимые статусы CSV: `SRC_SAVED`, `PREVIEW_SAVED`, `NO_FILE`, `ALREADY_OK`.
* Перезапись допускается только для файла `PREW_` при явно включённой настройке; оригиналы в папке назначения никогда не заменять. Параллельную обработку ограничивать выбором пользователя от 1 до 10 потоков и сохранять этот выбор.
* Публичные классы и нетривиальные методы документировать Javadoc. Предпочитать стандартную библиотеку и зрелые зависимости самописным парсерам.
* Перед сдачей выполнять `gradle test` и `gradle build`.

## Ограничение

Превью можно восстановить только когда Windows Shell/кэш Explorer или установленный провайдер Яндекс Диска возвращает реальную миниатюру. Без кэша и без полного файла восстановить изображение невозможно.
